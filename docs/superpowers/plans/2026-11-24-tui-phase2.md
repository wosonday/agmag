# TUI Phase 2 (whole `agm tui` on ratatui) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `agm tui` becomes a full-screen ratatui app (global screen + the existing project board as a second screen) with a command bar; `agm tui --plain` keeps today's line UI; both front ends run commands through one shared dispatcher.

**Architecture:** Task 0 (CEO) freezes the shared types and stubs. Five parallel tracks then own disjoint files: A extracts the command dispatcher in the binary crate (behaviour-neutral), B the ANSI bridge, C the global-screen state/keys, D the global-screen rendering, E the app loop that hosts both screens. Task F (CEO) wires `agm tui` / `--plain` and integrates.

**Tech Stack:** Rust 2024, ratatui 0.30 (`ratatui::crossterm`), existing `agmag` modules.

**Spec:** `docs/superpowers/specs/2026-11-24-tui-phase2-design.md` (read the "Builder-check answers" section: they are binding).

## Global Constraints

- Gates for every task: `cargo test`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` clean.
- No change to what any command does, its arguments, its error/notes text, or the data a section shows.
- `--plain` behaviour unchanged; existing `tui.rs`/`dashboard` tests stay green without edits (except moving `NoteKind`, done in Task 0).
- Human-only: `detect_caller` once at start, fail-closed; `Caller::User { confirmed: true }` only inside `dispatch` after a pending confirmation receives `y`.
- Terminal always restored (reuse the board's `TermGuard` + panic hook); only `KeyEventKind::Press`/`Repeat` act.
- Untrusted text sanitized (`dashboard::sanitize_one_line`) before it reaches a `Span`; the ANSI bridge keeps only SGR `ESC[…m`.
- Unknown values render `-`. Themes: the board's three palettes and the `board.theme` setting.
- `view`: same `Section` list, `MAX_VIEW = 3`, setting key `tui_view`; Messages pinned and never counted.

## Review Focus

1. A confirmation is pending and the user types something else, presses `esc`, or the app refreshes meanwhile → cancelled exactly as `--plain` ("cancelled" / "cleanup cancelled"); never executed. Tests in Tasks A and C.
2. `cleanup` list shown, then candidates change before `cleanup 1` → same stale-list semantics as `--plain` (the dispatcher keeps `cleanup_list`). Test in Task A.
3. Many terminals / inbox rows (40+) and long names → selected row stays visible, nothing drawn outside its panel. Test in Task D.
4. Board entered from the app, then `q` → back to the global screen with the command bar focused and typing works; `ctrl+c` in either screen quits and restores the terminal. Test in Task E (state level) + manual.
5. Command bar at narrow widths (< 40 columns) and very long input → input scrolls horizontally, cursor visible, no panic. Test in Task D.

### Task A: Shared dispatcher (binary crate)

**Files:** create `src/tui_cmd.rs`; modify `src/tui.rs`, `src/main.rs` (`mod tui_cmd;` only); tests in-file (`#[cfg(test)]` in `tui_cmd.rs`).

**Interfaces:** Consumes `NoteKind`, `Outcome`, `Dispatched` (Task 0). Produces:

```rust
pub struct Ctx<'a> { pub store: &'a Store, pub cfg: &'a Config, pub hc: &'a dyn Hc, pub who: Caller, pub now_ms: i64 }
pub struct CmdState { /* view, scope, pending, cleanup_list, cleanup_selected, roots_cache — moved from tui::run */ }
impl CmdState { pub fn new(store: &Store) -> Self /* view = load_view(store) */; pub fn view(&self) -> &[Section]; pub fn scope(&self) -> Option<&ProjectKey>; }
pub enum Front { Plain, App }
pub fn dispatch(line: &str, st: &mut CmdState, ctx: &Ctx, front: Front) -> Dispatched;
```

Rules:
- Move the whole per-line handling of `tui::run` (pending cleanup confirmation, pending kill/interrupt confirmation, `match parse_command`) into `dispatch`, unchanged in effect and text. `NeedsConfirm(prompt)` is returned where `--plain` sets the confirmation note today; the prompt is the same `confirmation_note(..)` text.
- `Front::Plain`: `cd <q>` found → `Outcome::OpenBoard(key)` (the plain loop calls `board::run` as today); `cd -t` sets scope as today. `Front::App`: `cd -t <q>` → `Note(Warn, "text project view: use `agm tui --plain`")`; `cd ..`/`cd /` → `Note(Ok, "already at all projects")` when no scope.
- `shown` blocks (`cd` list, `show`, cleanup list) → `Outcome::Shown(text)`; the plain loop keeps printing them exactly where it does today (`render_frame` keeps taking `cleanup_list` — expose it via `CmdState::cleanup_list() -> Option<&[CleanupCandidate]>`).
- `tui::run` (plain) keeps: stdin thread + resume hand-shake, scan, snapshot, frame rendering, `scoped_text`. It builds `Ctx` per line and maps `Dispatched` to its existing `note` / `shown` / board call / quit.
- `Dispatched.view` is always `st.view().to_vec()`.

- [ ] **Step 1: Failing tests** (temp `Store`, fake `Hc` recording calls, `who = Caller::User { confirmed: false }`): `kill_needs_confirm_then_y_kills` (dispatch `kill t1` → `NeedsConfirm` containing "kill t1"; then `y` → fake Hc saw kill, note Ok "killed t1"); `kill_confirm_other_input_cancels` (`kill t1`, then `n` → `Note(Warn, "cancelled")`, no kill); `agent_caller_never_confirms` (who = agent → kill refused exactly as today); `cleanup_two_step_and_stale_list` (`cleanup` → `Shown` list; `cleanup 1` → `NeedsConfirm`; `x` → "cleanup cancelled"); `view_sets_and_returns_view` (`view quota inbox` → `Dispatched.view == [Quota, Inbox]`, setting saved); `policy_toggles`; `cd_found_opens_board_both_fronts`; `cd_t_plain_scopes_app_warns`; `unknown_command_is_err_note`; `quit_is_quit`.

### Task C: Global state and keys

**Files:** `src/board/global.rs` (tests in-file).

Behaviour (all in `on_key`; Release ignored; `ctrl+c` → `Quit` always):
- Popup `Confirm`: printable → append; Backspace; `⏎` → `Run(input)` and close; `esc` → `Run("")` and close (empty line = cancel in dispatch).
- `Focus::CmdLine`: printable → insert at cursor; Backspace/Delete/←/→/Home/End edit; `↑`/`↓` history (last 50, no consecutive duplicates); `⏎` with non-blank text → push history, `Run(text)`, clear; `esc` → clear; `tab`/`shift+tab` → first/last visible panel of `data.view` (+ Messages).
- `Focus::Panel(sec)`: `tab` cycles visible panels then back to CmdLine; `↑↓`/`jk` select (Terminals: `sel_terminal` over `snap.terminals`; Inbox: `sel_inbox` over `snap.inbox`) or scroll (other sections, `scroll[sec]`); `PgUp`/`PgDn` scroll the Output panel when `data.output` is Some; `⏎` on Terminals → `OpenBoard(address)`, on Inbox → `Run("show <id>")`; `r` on Inbox → CmdLine focused with text `reply <id> `; `d` → `done <id>`; `s` on Terminals → `send <name-or-address> `; `t` → theme next + `SaveTheme`; `q` → `Quit`; `?` → note `(Ok, "tab panels · ↑↓ select · ⏎ open · r reply · d done · s send · t theme · q quit")`; any printable key not bound in a panel → focus CmdLine and insert it.
- `sync(data)`: keep selections by address/id, nearest neighbour when gone, None when empty; if focus is a panel no longer in view → CmdLine.

### Task E: App loop and screens

**Files:** `src/board/app.rs`, `src/board/mod.rs`; tests `tests/tui_app_test.rs` + in-file.

**Interfaces:** Consumes Task 0 types; `board::{load_data, apply_effect, BoardState, TermGuard (make pub(crate)), initial_state}`; `GlobalState::{on_key,sync}`, `draw_global` (stubs until C/D merge — test only pure helpers here).

Rules:
- Split `board::run_loop` into `pub(crate) struct BoardScreen { state, data, cache }` with `fn refresh(&mut self, store, cfg, now)`, `fn draw(&self, frame, theme, ascii)` and `fn on_key(&mut self, key, store, hc, now) -> BoardKeyResult { Stay, Leave }` (Leave = the board's `Effect::Quit`); `board::run` uses it and behaves exactly as today (existing board tests unchanged).
- `run_app`: guard + panic hook like `board::run`; `enum Screen { Global, Board(BoardScreen) }`; every refresh: `scan`, `snapshot`, `compute_roots`/`list_projects` → `project_of`, `sync`. Keys: `ctrl+c` → quit (both screens); Global → `GlobalState::on_key`: `Run(line)` → `dispatch(line)` → apply `Dispatched`: `view` replaces `data.view`; `Note` → state.note; `Shown` → `data.output = Some`; `NeedsConfirm(p)` → `popup = Confirm{p, ""}`; `OpenBoard(key)` → `Screen::Board(BoardScreen::new(key))`; `Quit` → return. `OpenBoard(address)` → `project_of[address]` or note `(Warn, "<name> has no project")`. Board → `BoardScreen::on_key`; `Leave` → `Screen::Global`, focus CmdLine.
- Extract the pure part as `pub(crate) fn apply_dispatched(state: &mut GlobalState, data: &mut GlobalData, d: Dispatched) -> Option<ProjectKey>` (returns the board to open) and `pub(crate) fn terminal_project(data: &GlobalData, address: &str, name: &str) -> Result<ProjectKey, String>`.
